# AWS CI/CD Lambda Project

## Objective
Automate the deployment process of an AWS Lambda function using GitHub and AWS CodePipeline.

## AWS Services
- AWS Lambda
- AWS CodePipeline
- AWS CodeConnections
- Amazon CloudWatch
- GitHub

## Workflow
Developer pushes code to GitHub → CodePipeline detects the change → CodePipeline deploys the updated Lambda function.

## Project Status
CI/CD pipeline is configured and tested successfully.
